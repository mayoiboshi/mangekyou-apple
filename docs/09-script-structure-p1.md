# 09 — 行内词法、符号和资源候选关系

P0 的整行分类发现了文本载体，但会把一行中的后续反斜杠片段留在首条记录的参数内。真实脚本可见 `if` 后紧接 `then`、制表符后的其他片段，以及带反斜杠的引用路径。新层只在引号之外寻找候选命令边界，保留每个字段和排版范围的原始字节位置。

这是一套**inferred 词法规则**，尚不是完整 QLIE 文法。原始字节范围和完整覆盖是 verified；是否每个候选边界都与引擎解析一致，以及所有 token 的执行含义，仍未验证。引号中的路径不拆分，无法解释的输入进入错误记录，不执行表达式。

## 语料与字节位置

379 个文件包含 254 份带 BOM 的 UTF-16LE 和 125 份可严格解码的 CP932；后者编码判断为 inferred。共有 7,398 行产生多个候选命令片段。`.s` 内有 245 种反斜杠 token 和 33 种行标记；把 `.txt` 也计入后行标记为 38 种，反斜杠 token 仍为 245 种。

P0 的 169 种是当时整行方法的 token 统计，不能用来估计完整解释器需要支持多少命令。本轮仍保留各包副本，且有未证实的语法假设，因此新数字也不是“已知操作码总数”。

位置通过逐字节增量解码生成，覆盖 UTF-16 代理对和 CP932 非规范别名，不依赖重新编码。BOM、行尾、制表符、缩进和填充空行均有来源范围。测试逐段验证无重叠、无遗漏和片段摘要，能重建全部合成输入字节。

## 标签、include 和变量候选

| 类型 | 实际数量 | 当前边界 |
|---|---:|---|
| 标签定义 | 1,868 | 保留每包/每文件位置，不假定 `!` 等于全局作用域 |
| include 记录 | 442 | 都能找到至少一个文件候选；根路径、相对路径、前导 `!` 的意义仍未确认 |
| `@@` 标签字面引用 | 3,106 | 2,966 有候选，140 没找到；不是运行时控制流图 |
| 无 `@@` 字面目标的 sub/jmp/go 记录 | 205 | 保留为未知，可能是计算目标或其他语法（Hypothesis），不直接称为动态跳转 |
| var/gvar/svar 声明样式 | 2,306 | 记录类型拼写与符号；存储宽度、作用域、生命周期未确认 |
| `$name=...` 定义样式 | 156 | 定义、RHS 摘要及原始位置可追溯，替换规则未实现 |
| `$...` 引用样式 | 4,919 | 美元前缀也可能是数值或其他语法，不把它们全判作宏 |

有明确文件参数时只在文件候选中查标签，文件不存在时不会悄悄改用无关的全局标签。没有文件参数时分列“同文件候选”“include 闭包假设”“语料全局回退假设”。循环 include 的图遍历有界，既不展开执行，也不据此确定加载顺序。

这些边统一标注 `execution_edge=not_tested`。含标签字面量的回调设置和调用/跳转可能具有不同含义（Hypothesis）；当前工具不把它们混称为真正调用。所有候选均带源文件、源 SHA-256、byte_offset、byte_length 和记录摘要。

## 资源标识符

在 P0 字面路径之外，新增有明确标记的“省略扩展名路径”“文件名 stem”“音频标记标识符”候选查找，得到 18,786 条有目录候选的关系，其中 18,492 条仅有一个目录项、294 条有多个目录项。

另有 2,735 条选定的字面引用尚未匹配，23,767 个含变量/模板/表达式特征的字段没有求值。后者是字段数，不是运行时资源数。不能因候选较多而忽略仍未覆盖的动态构造与查找规则。

单一 stem 匹配只表示目录里找到一个拼写候选，不证明引擎会在该目录搜索、默认该扩展名或选择该包。背景、立绘、语音、BGM、音效、动画的关系类型仍是 Unknown。P0 的 2,639 条字面路径图与本轮候选图采用不同规则，不能把增加的关系称为新验证的运行时绑定。

公开表每类最多 200 项，完整表及完整 IR 在 `private/p1/`。报告不含台词正文或字段值；未展开的字段保留摘要和来源。完整元数据的统计在截取之前计算，截取数量明确披露。
