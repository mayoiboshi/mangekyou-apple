# 00 — 范围与验收解释

本次仅研究第四作《美少女万華鏡 -罪と罰の少女-》。用户最初无数据，随后提供本机游戏目录；真实结果覆盖了先前的无数据基线。其他系列源码只用作对照，不以其行为证明第四作行为。

P0 已执行 A–F：原始目录清点、FilePack 源码及索引验证、受限资源解码、剧本词法结构与字节位置、静态文件引用候选、路线与风险比较。当时没有开发引擎、播放器、SwiftUI 界面或完整资源转换流水线；P0 报告保持历史快照。后续用户明确授权完整应用，已启动原生基础开发，当前状态与新增范围见 `docs/31-native-app-foundation.md`。始终没有运行任何游戏或汉化 EXE/DLL。

本阶段的 `verified` 表示指定事实在指定范围成立。例如“PACK 索引可列举”“某 DPNG 可以转换”“物理行顺序可恢复”，均不表示该包所有内容正确、动画还原正确、脚本执行正确或游戏可通关。

| 状态 | 使用条件 | 示例 |
|---|---|---|
| verified | 有源码定位、签名、明确执行的测试或文件级证据 | 真实 10 包均为 FilePackVer3.1 |
| inferred | 词法候选、编码假设或依据不足的解释 | 无 BOM 的 CP932；某标记可能代表控制流 |
| unsupported | 当前实现不支持、失败或缺少语义实现 | 执行条件表达式、还原存档状态 |
| not_tested | 没有实际做相应验证 | M4 性能、原版时间线、纯净版真实性 |

P0 的验收允许以源码与实际脚本证据说明现有工具不足，而不要求在 P0 恢复完整语义。当前可进入限定的 P1 调查；这不是对完整原生移植可行性的无条件保证。验收逐项结果在 `reports/p0/acceptance.json`。

原目录仅以只读方式打开。输出树与输入树不得重叠，逐级拒绝符号链接。私有副本和完整本地报告不进入 Git；公开摘要不保存商业台词、图像、声音、原始资源字节或密钥。所有网络请求只获取工具源码、依赖或公开文档，不含游戏数据。

独立重现命令见 README；无数据测试、真实数据采样、摘要发布是显式分开的步骤。真实报告失效或输入变化时应重新生成，不沿用旧的成功状态。
