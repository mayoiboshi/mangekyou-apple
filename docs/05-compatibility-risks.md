# 05 — 主要风险与未支持项

| 优先级 | 风险 | 当前证据 | 解除方式 |
|---|---|---|---|
| 阻塞 | 没有完整脚本执行语义 | 169 类词法 token；msg-tool 只提取消息 | 对真实宏、表达式、调用、循环、变量作用域逐项建档；未知保持停止条件 |
| 阻塞 | 包覆盖/补丁顺序 | 137 种 `.s` 逻辑路径跨包重复 | 分离原包/补丁和汉化层；取得静态加载规则证据，后续经授权的原引擎对照 |
| 阻塞 | 未验证存档和系统状态 | SaveData 仅清点；没有执行引擎 | 定义变量、调用栈、演出、音频、随机状态及版本迁移前先调查真实存档结构 |
| 高 | 演出、动画与复合容器未知 | 9 个样本是 ABMP12，内部未展开；Theora 可识别 | 受限分析容器内部、时间参数、图层和同步；不可仅播放媒体即称一致 |
| 高 | DPNG 透明重叠差异 | Python paste 行为已验证，原引擎未比较 | 构建有重叠/半透明的代表样本，后续比对原引擎像素/合成规则 |
| 高 | 混合安装来源 | 两份汉化 EXE、补丁 RAR、版本文本 1.2 | 保留现有摘要；另取得用户持有的干净版作对照，不擅自修改现有安装 |
| 高 | 第三方许可缺口 | qlie-unpack 与 mangekyou_util 没有明确许可证 | 取得许可或换用许可明确且通过同样样本验证的实现 |
| 中 | 仅代表样本正确 | 410 项相对 10,940 游戏条目，且小文件偏置 | 覆盖每种变体、大图、长音频、特殊容器；不要把索引成功当成完整解包成功 |
| 中 | 系统字体、插件/设置行为 | 有 DLL/配置但未执行/完整解释 | 调查字体回退、字形度量、换行、音频循环和外部功能的调用点 |
| 中 | 抗异常输入边界 | 有尺寸/路径/超时限制；macOS 不接受 RLIMIT_DATA | P1 引入可靠内存隔离、更多畸形输入回归；不直接暴露不受限上游解包器 |

当前不支持条件求值、标签作用域、宏展开、调用/返回、变量写入、分支执行、资源优先级、存档还原、图层演出、媒体同步或游戏运行。没有 M4/M4 Pro 性能结论；仅确认本机 arm64 研究工具可运行。

安全边界：逐级拒绝输入与输出符号链接，归档成员拒绝绝对路径、驱动器、`..`、NUL 和冒号流；大小写/Unicode 规范化冲突不静默覆盖。研究副本写入 private，已存在但不同的内容拒绝覆盖。嵌入 key 只驻留内存，安装器和汉化 EXE 不执行，补丁压缩包不展开。

存在少数上游解析宽松点：未验证全部 V3.1 key/hash 元数据，未知大方法号被送入 method2 路径等。当前真实样本未报解码错误不消除这些风险。报告原始字段，后续逐项确认，不把异常值解释成新功能。
